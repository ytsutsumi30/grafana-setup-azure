# 出荷検品アプリ 現場レビュー用チェックリスト

作成日: 2026-07-08

## 目的

出荷検品アプリの POC を現場担当者、管理者、システム担当者で確認し、業務運用に必要な不足点を洗い出す。

レビュー対象は、出荷指示選択から PPS / QR 検品、出荷完了、履歴、帳票、監査ログまでの一連フローとする。

## 前提

- Azure Container Apps 上の POC 環境を利用する。
- M365 ログイン済みブラウザで確認する。
- API は M365 Bearer token 付きの画面操作を前提にする。
- 現時点ではログインユーザー全員を同一権限として扱う。
- HTML 印刷とブラウザ PDF 保存を帳票運用の前提にする。

## 事前準備

- [ ] レビュー用の出荷指示を用意する。
- [ ] 複数品目を含む出荷指示を用意する。
- [ ] 1 品目に複数ロットがあるデータを用意する。
- [ ] QR 検品 OK になる QR / ロットを用意する。
- [ ] 未引当ロット、別品目、重複スキャンの確認用データを用意する。
- [ ] 完了後修正を確認できる出荷済みデータを用意する。
- [ ] 印刷または PDF 保存できる端末、プリンタ設定を確認する。

## レビュー参加者

- [ ] 出荷検品担当者
- [ ] 倉庫 / 現場リーダー
- [ ] 品質管理担当者
- [ ] 管理者 / 承認者
- [ ] システム担当者

## 業務フロー確認

### 出荷指示選択

- [ ] 出荷指示一覧から対象指示を見つけられる。
- [ ] 顧客名、出荷予定日、ステータスが識別しやすい。
- [ ] 複数品目の出荷指示であることが分かる。
- [ ] 既存の単一品目データも問題なく表示される。

### 品目 / ロット / 数量確定

- [ ] 品目を選択すると、その品目のロット候補が表示される。
- [ ] ロット番号、保管場所、数量が現場で判断できる情報量になっている。
- [ ] 適正ロットを選択できる。
- [ ] 出荷数量を入力できる。
- [ ] 数量確定後、未確定品目が残っている場合に次の品目へ進める。
- [ ] 全品目確定後、PPS / 出荷作業へ進める。
- [ ] PPS 開始後の変更が通常操作と区別されている。

### PPS / QR 検品

- [ ] PPS 画面で複数品目、複数ロットの引当が確認できる。
- [ ] QR スキャン直後に数量入力できる。
- [ ] 入力数量が残数量を超える場合に警告される。
- [ ] 正しい QR / ロットは OK として記録される。
- [ ] 未引当ロットは NG として記録され、検品数量に加算されない。
- [ ] 別品目の QR は NG として記録され、検品数量に加算されない。
- [ ] 重複スキャンは警告され、追加カウントされない。
- [ ] NG 理由分類とコメントが現場で入力しやすい。
- [ ] 全引当数量が QR 検品 OK になるまで出荷完了できない。

### 出荷完了

- [ ] 出荷完了条件が画面上で分かる。
- [ ] 未完了の品目、ロット、数量が分かる。
- [ ] 出荷完了操作が誤操作しにくい。
- [ ] 出荷完了後、履歴画面で状態を確認できる。

### 完了後修正

- [ ] 出荷完了後に数量またはロット修正ができる。
- [ ] 修正理由の入力が必須になっている。
- [ ] 修正コメントを入力できる。
- [ ] 修正前後の差分が履歴画面で分かる。
- [ ] 修正内容が監査ログに残る。
- [ ] 完了後修正が帳票上で修正版として識別できる。

## 帳票確認

### 出荷検品結果票

- [ ] 出荷指示情報が表示される。
- [ ] 品目別検品結果が表示される。
- [ ] ロット別検品結果が表示される。
- [ ] NG / 警告スキャンが表示される。
- [ ] 主要監査イベントが表示される。
- [ ] 帳票発行履歴が表示される。
- [ ] 初版、再発行、修正版、修正版・再発行が区別できる。
- [ ] HTML 印刷でレイアウトが崩れない。
- [ ] ブラウザ PDF 保存で運用できる。

### ロット別出荷実績票

- [ ] ロット別出荷実績が表示される。
- [ ] QR / スキャン単位の実績が表示される。
- [ ] 数量、ロット、品目、結果が追跡できる。
- [ ] 帳票発行履歴が表示される。
- [ ] HTML 印刷でレイアウトが崩れない。
- [ ] ブラウザ PDF 保存で運用できる。

### 承認欄 / 現場項目

- [ ] 作業者、確認者、承認者欄が運用に合っている。
- [ ] 追加すべき帳票項目がない。
- [ ] 不要な項目がない。
- [ ] 表示名称が現場用語と一致している。

## 履歴 / 監査ログ確認

- [ ] 出荷指示単位で履歴を確認できる。
- [ ] 品目別の状況を確認できる。
- [ ] ロット別の状況を確認できる。
- [ ] QR / スキャン単位の履歴を確認できる。
- [ ] 出荷完了イベントを確認できる。
- [ ] 完了後修正イベントを確認できる。
- [ ] 帳票出力イベントを確認できる。
- [ ] 誰が、いつ、何を、なぜ変更したか確認できる。
- [ ] 検索、絞り込み、ページングとして追加すべき条件を洗い出す。

## 認証 / 権限確認

- [ ] M365 ログインできる。
- [ ] 未ログイン時に保護対象 API が `401` になる。
- [ ] 現時点の全員同一権限で POC レビューに支障がない。
- [ ] 将来分けるべき権限を洗い出す。
- [ ] 閲覧、検品、修正、管理者の役割分離が必要か確認する。

## 運用 / 監視確認

- [ ] Azure Container Apps の稼働状態を確認できる。
- [ ] Application Insights / Log Analytics で障害調査できる。
- [ ] Grafana Cloud に出したい業務メトリクスを洗い出す。
- [ ] 出荷完了数、NG 件数、重複スキャン数、完了後修正数、帳票再発行数が必要か確認する。
- [ ] 障害時の一時運用、再処理、問い合わせ窓口を確認する。
