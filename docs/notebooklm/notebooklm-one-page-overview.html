出荷検品・製造業務 POC 1枚概要

QR・ロット・在庫・受発注・製造・トレーサビリティをつなぐ現場向け業務基盤
NotebookLM 連携用
更新日: 2026-07-09
配置: AI-Memory / projects / prj3 / notebooklm

目的

  • 出荷検品アプリ本体の完成度を上げる。
  • QR とロットを軸に、入庫から出荷完了後の修正まで追跡する。
  • 業務イベント単位で監査ログを残す。
  • 製造業向けに受発注、在庫、棚卸、製造、OCR、監視へ拡張する。
POC 方針: まず画面側制御を優先し、API 認証とバリデーションは段階的に厳格化する。

業務フロー

発注・入庫発注から入庫予定を作成し、QR/ロット単位で入庫。
在庫管理在庫残高、在庫移動、状態、ロケーションを追跡。
受注・出荷受注から出荷指示を生成し、数量とロットを確定。
QR 検品確定済みロット引当を正として QR 検品し、完了判定。
棚卸実在庫をカウントし、差異を監査ログ付きで反映。
OCR帳票テキストから受注や入庫候補へ変換。
製造材料投入、工程実績、完成品入庫をロットで接続。
トレースQR、ロット、伝票、製造指図を横断検索。

技術構成

Frontend静的 HTML、Vanilla JS、PWA、M365 ログイン UI。
APINode.js / Express。業務 API と監査ログ。
DBSupabase PostgreSQL。ロット、QR、在庫、伝票。
HostingAzure Container Apps。japaneast。
AuthM365 ログイン、Bearer token 運用へ移行。
MonitoringGrafana Cloud 最小監視。
