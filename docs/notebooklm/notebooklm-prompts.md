# NotebookLM 質問テンプレート

## 全体把握

- この POC の目的、対象業務、現在の実装済み範囲を要約してください。
- 出荷検品、在庫、発注、入庫、受注、出荷指示、棚卸、OCR、製造、トレーサビリティ、監視に分けて、機能一覧を表にしてください。
- 推奨実装順に対して、完了済み、実装中、未着手、リスクありを整理してください。

## 現場レビュー

- 現場担当者向けに 10 分で説明するデモ台本を作ってください。
- QR とロット管理の業務メリットを、製造業の現場担当者向けに説明してください。
- 出荷完了後の数量・ロット修正を許可する場合の統制ポイントを整理してください。

## 設計レビュー

- QR 個体 ID とロット番号を将来分離する場合の DB、API、画面、監査ログの変更点を整理してください。
- 画面側制御を優先し API を緩くする POC 方針のリスクと、次段階で強化すべき API バリデーションを挙げてください。
- 業務イベント単位で監査ログを記録する設計として、不足しているイベント候補を洗い出してください。

## Azure / Supabase / 認証

- Azure Container Apps、Supabase、M365 認証、Grafana Cloud の構成を説明してください。
- POC から本番に進む場合に強化すべきセキュリティ、運用、監視の項目を表にしてください。
- Supabase 移行で注意すべきネットワーク、接続方式、認証情報管理を整理してください。

## 次アクション

- 次の 2 週間で実装すべきタスクを、優先度、理由、受け入れ条件付きで一覧化してください。
- 未完了フェーズのうち、業務価値が高く実装リスクが低い順に並べてください。
- テスト観点を、API、画面、業務シナリオ、認証、監査ログ、監視に分けて整理してください。
