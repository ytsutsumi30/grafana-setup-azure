# NotebookLM レビュー会議アジェンダ

## 会議名

出荷検品・製造業務 POC レビュー

## 目的

NotebookLM に投入した資料をもとに、現在の POC の完成度、業務適合性、次アクションを確認する。

## 参加者

- 業務担当
- 現場担当
- システム担当
- インフラ / Azure 担当
- 品質管理担当

## 事前準備

NotebookLM に次のソースを追加しておく。

1. `notebooklm-one-page-overview.pdf`
2. `notebooklm-combined-source.pdf`
3. `notebooklm-prompts.md`
4. `notebooklm-review-briefing.md`

## 60分アジェンダ

| 時間 | 内容 | 確認ポイント |
|---:|---|---|
| 0-5分 | 目的確認 | 今日決めることを確認する |
| 5-15分 | NotebookLM 概要確認 | POC の対象業務、完了済み範囲、未完了範囲 |
| 15-25分 | 出荷検品レビュー | 複数品目、複数ロット、QR 検品、完了後修正 |
| 25-35分 | 在庫・受発注レビュー | 発注、入庫、在庫残高、受注、出荷指示生成 |
| 35-45分 | 拡張機能レビュー | 棚卸、OCR、製造指図、トレーサビリティ |
| 45-52分 | 技術・運用レビュー | Azure、Supabase、M365 認証、Grafana Cloud |
| 52-58分 | 次アクション決定 | 優先順位、担当、期限 |
| 58-60分 | クロージング | 決定事項と宿題の確認 |

## 会議中に NotebookLM へ聞く質問

```text
この POC の完成度を、業務領域ごとに 5 段階で評価し、理由を説明してください。
```

```text
現場レビューで最も確認すべきリスクを 10 件挙げてください。
```

```text
次の 2 週間で実装すべきタスクを、優先度、理由、受け入れ条件付きで表にしてください。
```

```text
本番化前に必ず解消すべきセキュリティ、監査、運用、監視の課題を整理してください。
```

## 会議後の成果物

- 決定事項
- 未決事項
- 次アクション
- リスク一覧
- 追加で NotebookLM に投入すべき資料
