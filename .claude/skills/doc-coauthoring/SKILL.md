# Doc Co-Authoring(3ステージ共同執筆)

## DO(やること)

- 冒頭で3ステージ方式を提案する。freeform希望ならそれに従う。
1. **Context Gathering**: 文書の読者・目的・締切・分量を確認 → 関連情報を雑多なまますべて出してもらい(貼り付け歓迎)、こちらから確認質問で穴を埋める。
2. **Refinement & Structure**: セクション単位で「確認質問 → ブレスト → 取捨選択 → ギャップ確認 → ドラフト → 反復」。一気に全文を書かない。完成が近づいたら全体の品質チェック。
3. **Reader Testing**: 文脈を持たない新しいClaude(サブエージェント)に完成稿を読ませ、読者が詰まる箇所・誤解・未定義用語・答えられない質問を検出 → 修正。終了条件は「新規の重大指摘が出なくなる」こと。

## DON'T(やらないこと)

- コンテキスト収集を飛ばして書き始める。
- 全文を一発生成して「どうですか」と返す。
- 自分だけで検証を完結させる(必ず読者視点テストを挟む)。

## OUTPUT FORMAT(出力の型)

- 完成ドキュメント(合意した構成に従う)
- Reader Testing の指摘一覧と、各指摘への対応(修正済み / 見送り+理由)
